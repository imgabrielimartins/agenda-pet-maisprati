# 🐾 AgendaPet

Landing page desenvolvida durante o programa **+praTi** com o objetivo de praticar HTML5, CSS3 e JavaScript, além de utilizar Git/GitHub para versionamento de código.

O projeto simula uma página de agendamento de serviços para pets, oferecendo uma interface moderna, responsiva e com integração à API ViaCEP para preenchimento automático de endereço.

## ✨ Funcionalidades

- Cabeçalho com navegação entre seções
- Seção principal com chamada para ação
- Cards de serviços (Banho, Tosa, Consulta e Passeio)
- Seção "Sobre"
- Formulário de contato/agendamento
- Integração com a API ViaCEP para busca automática de endereço pelo CEP
- Interações em JavaScript (rolagem suave e mensagem de confirmação)
- Layout responsivo para desktop e dispositivos móveis

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript (ES6+)
- ViaCEP
- Git e GitHub

## 🚀 Como executar o projeto

1. Clone este repositório:

```bash
git clone https://github.com/imgabrielimartins/agenda-pet-maisprati.git
```

2. Acesse a pasta do projeto:

```bash
cd agendapet-maisprati
```

3. Abra o arquivo `index.html` no navegador.

## 🌐 API utilizada

Este projeto utiliza a API pública ViaCEP para preencher automaticamente os campos de endereço a partir do CEP informado pelo usuário.

- Documentação: https://viacep.com.br
